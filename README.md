# House Price Prediction

## Project Overview
This project focuses on predicting residential house prices using Machine Learning regression techniques. It uses property characteristics to estimate the expected selling price.

## Objective
To develop a predictive model that estimates house prices based on property features such as living area, quality, location, bathrooms, bedrooms and other housing characteristics.

## Dataset
- Ames Housing Dataset
- Residential property information
- Numerical and categorical features

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and understanding
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Feature engineering
5. Handling missing values
6. Categorical feature encoding
7. Regression model development
8. Hyperparameter tuning
9. Model evaluation

## Machine Learning Algorithms
- Linear Regression
- Ridge Regression
- Lasso Regression
- Elastic Net
- Random Forest
- Extra Trees
- Gradient Boosting
- Histogram Gradient Boosting

## Model Evaluation
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Results
Best recorded model: Log-target Extra Trees Regression

- R² Score: 90.58%
- MAE: Approximately $16,713
- RMSE: Approximately $26,887
